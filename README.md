# 🧩 Java Collections Practice

This repository contains my **Java Collection Framework** practice programs.  
It includes examples of different collection classes like **List**, **Map**, and their implementations.

## 📂 Folders
- **Java_8/** – Programs on @FunctionalInterfaces, Lambda expression, method references,Streams, Functional Programming, etc.  

- **1_interview/** – Commonly asked interview problems and solutions.  
- **List_interface/** – Programs on ArrayList, LinkedList, Vector, Stack, etc.  
- **Map_interface/** – Programs on HashMap, LinkedHashMap, WeakHashMap, etc.  
- **Questions/** – Practice questions for List and Map.  
- **Queue/** – Practice questions for Queue, Priority Queue etc.  
- **Sets/** – Programs on Set,HashSet, LinkedHashSet, TreeSet, etc.  
- **Streams/** – Programs on Intermediate and Terminal Operations, Collectors, Parallel Streams, Question etc.
- **Practice/** - Programs for practicing other questions. Every folder have ```base.txt``` file.


## 🎯 Purpose
This repo is created for **my own learning and hands-on practice** with Java Collections(Like AarrayList, HashMap, Streams, etc), and other concepts like (Arrays, Recursion, Conditions etc)

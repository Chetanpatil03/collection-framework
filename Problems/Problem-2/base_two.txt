Here is a strong list of **Java coding practice questions**, from beginner to advanced. These are commonly asked in **interviews, exams, and competitive coding**.

---

# ✅ **Beginner-Level Java Coding Questions**

1. Write a program to check if a number is even or odd.
2. Find the largest of three numbers.
3. Check if a number is prime.
4. Print Fibonacci series up to N terms.
5. Reverse a number.
6. Check if a string is a palindrome.
7. Count vowels and consonants in a string.
8. Find the factorial of a number.
9. Swap two numbers without using a third variable.
10. Find the sum of digits of a number.

---

# 🔥 **Array Coding Questions**

1. Find the largest and smallest number in an array.
2. Reverse an array.
3. Find the missing number in an array of 1 to N.
4. Remove duplicate elements from an array.
5. Find the second largest number in an array.
6. Find the frequency of each element in an array.
7. Rotate an array (left/right).
8. Merge two sorted arrays into a single sorted array.
9. Check if two arrays are equal.
10. Find pairs in an array whose sum is equal to a given number.

6. Find duplicate characters in a string.
7. Check if a string contains only digits.
8. Convert a string to a number without using built-in parsing.
9. Find the longest word in a sentence.
10. Capitalize the first letter of each word.

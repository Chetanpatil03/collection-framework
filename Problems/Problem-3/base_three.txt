# 🔥 **Intermediate-Level Coding Questions (More)**

### **Arrays (Intermediate)**

1. Remove all occurrences of a given element from an array.
2. Find the longest increasing subarray.
3. Find the leader elements in an array (elements greater than all to their right).
4. Move all zeros to the end of the array.
5. Sum of all subarrays.

### **Strings (Intermediate)**

6. Implement your own `substring()` method.
7. Check if a string is a valid palindrome after removing non-alphanumeric characters.
8. Longest palindrome substring (medium difficulty).
9. Check if two strings are isomorphic.
10. Compress a string (e.g., aaabb → a3b2).

### **Mathematical / Logical**

11. Generate all combinations of balanced parentheses for n pairs.
12. Print all subsets of a given set.
13. Check if number is happy number.
14. Find digital root of a number.
15. Convert Roman numerals to integer.

### **Collections/Maps**

16. Count word frequency in a paragraph (use HashMap).
17. Sort list of objects using Comparator (by age, name, etc.).
18. Group items using HashMap (e.g., group students by grade).
19. Remove duplicates from list while maintaining order.
20. Find intersection & union of two ArrayLists.

### **LinkedList Basic**

21. Insert a node at beginning/end/middle.
22. Delete node by value.
23. Find length of linked list.
24. Reverse linked list (iterative).
25. Find middle element of linked list.

### **Intermediate Logic Problems**

26. Find first repeating and first non-repeating element in an array.
27. Find sum of unique elements.
28. Replace every element with the greatest element to its right.
29. Check if array is sorted (ascending or descending).
30. Implement basic calculator (+, -, *, /) without using eval.
